## Output

```js
console.log("Hello World");     // string
console.log(3);                 // number
console.log(3 + 4);            // → 7 (math)
console.log("3+4");            // → "3+4" (string, no math)
```

**Mixing values in output:**
```js
age = 24;
console.log("My age is", age);              // → My age is 24
console.log("My age is" + age);             // → My age is24 (no space)
console.log("My age is " + age + " and i am young"); // → My age is 24 and i am young
console.log("My age is", age, "and i am young");     // → My age is 24 and i am young
```

> Using `,` in `console.log` adds a space automatically. Using `+` concatenates directly.

## Variables

### Dynamic Typing
JS does **not** require declaring data types. A variable can hold any type at any time.

```js
a = 10;
console.log(a + 3);  // → 13.6 (if a = 10.6)
x = "raghav";
console.log(x);      // → raghav
```

### `var` / `let` / `const`

| Feature | `var` | `let` | `const` |
|--------|-------|-------|---------|
| Reassignable | ✅ | ✅ | ❌ |
| Redeclarable | ✅ | ❌ | ❌ |
| Block scoped | ❌ | ✅ | ✅ |

```js
var a = 4;   a = 6;     // ✅ works
var a = 7;              // ✅ redeclaration allowed with var

let a = 4;  a = 6;     // ✅ reassignment ok
let a = 7;              // ❌ SyntaxError: already declared

const a = 4; a = 6;    // ❌ TypeError: Assignment to constant variable
```

> In C++, `const int a = 4; a = 10;` → error: cannot assign to const variable  
> In C++, `int a = 5; int a = 6;` → error: redefinition of 'a'  
> JS with `var` allows redeclaration; JS with `let`/`const` does not.

## Operators

```js
let a = 10, b = 4;

console.log(a + b);           // 14
console.log(a - b);           // 6
console.log(a * b);           // 40
console.log(a / b);           // 2.5
console.log(a % b);           // 2  (remainder)
console.log(2 ** 7);          // 128 (exponentiation)
console.log(Math.floor(a/b)); // 1  (integer division)
```

## Data Types & `typeof`

```js
a = 4;          // number
b = 3.14;       // number (no separate float type in JS)
c = "raghav";   // string
d = true;       // boolean
e = 'q';        // string (single quotes = string, not char like C++)

console.log(a, typeof(a));  // → 4 number
console.log(b, typeof(b));  // → 3.14 number
console.log(c, typeof(c));  // → raghav string
console.log(d, typeof(d));  // → true boolean
console.log(e, typeof(e));  // → q string
```

> In C++: `int`, `float`, `char`, `bool` are separate. In JS, integers and floats are both `number`.

## `==` vs `===`

| Operator | Checks | Type Coercion |
|----------|--------|---------------|
| `==` | Value only | ✅ Yes |
| `===` | Value + Type | ❌ No |

```js
a = 5;
b = '5';

console.log(a == b);   // → true  (value same, types ignored)
console.log(a === b);  // → false (number ≠ string)
```

> In C++, comparing `int a = 5` with `'5'` (char, ASCII 53) using `==` returns `0` (false), since it parses the char as integer 53.  
> C++ uses `stoi(s)` to convert string to int.

## Loops

```js
// for loop
for (let i = 1; i <= 10; i++) {
    console.log(i);
}

// while loop
let i = 1;
while (i <= 15) {
    console.log(i);
    i++;
}

// do-while loop (executes at least once)
let i = 1;
do {
    console.log(i);
    i++;
} while (i <= 15);
```

## Key Differences: JS vs C++

| Concept | C++ | JavaScript |
|--------|-----|-----------|
| Data type declaration | Required (`int`, `float`, etc.) | Not required (dynamic) |
| `const` reassignment | Compile error | TypeError at runtime |
| Variable redeclaration | Error | Allowed with `var` |
| Integer division | `7/4 = 1` | `7/4 = 1.75` (use `Math.floor`) |
| Char type | Separate (`char`) | No char; single quotes = string |
| String-to-int | `stoi(s)` | `parseInt(s)` / `Number(s)` |
| `==` with mixed types | Parses strictly | Coerces types |
