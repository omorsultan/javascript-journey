# JavaScript Notes Part 2 — Truthy/Falsy, Strings, Template Literals & Arrays

## 1. Truthy & Falsy Values

> Falsy values = everything except: `0`, `""` (empty string), `null`, `undefined`, `NaN`, `false`. Everything else is **truthy**.

```js
if(undefined){
    console.log("Hello");   // truthy
}
else console.log("mello");   // falsy

console.log(typeof(a));
```
Output:
```
mello
undefined
```
➡️ `undefined` is **falsy**, so the `if` block is skipped and the `else` runs, printing `mello`. `typeof(a)` (where `a` was never declared) also prints `undefined`.

## 3. String Built-in Methods

### `toUpperCase()` / `toLowerCase()` — Strings Are Immutable

```js
let s = "Raghav Garg";
console.log(s);
console.log(s.toUpperCase());
console.log(s);
// console.log(s.toLowerCase());
```
Output:
```
Raghav Garg
RAGHAV GARG
Raghav Garg
```
➡️ `toUpperCase()` does **not modify** the original string — it returns a **new** uppercased string. The original `s` stays unchanged unless reassigned.

```js
let s = "Raghav Garg";
console.log(s);
s.toUpperCase();        // ye kucch nahi karta (this does nothing on its own)
console.log(s);
```
Output:
```
Raghav Garg
Raghav Garg
```
➡️ Calling `s.toUpperCase()` without storing the result has no visible effect — the return value is simply discarded.

```js
let s = "Raghav Garg";
console.log(s);
s.toUpperCase();
let s2 = s.toUpperCase();
console.log(s, s2);
```
Output:
```
Raghav Garg
Raghav Garg RAGHAV GARG
```
➡️ Storing the result in a new variable `s2` is how you actually capture the transformed string, while `s` remains untouched — confirming strings are **immutable** in JS.

### `trim()` — Removing Leading/Trailing Whitespace

```js
let s = "  Raghav Garg  ";
console.log(s, s.length);
let s2 = s.trim();
console.log(s2, s2.length);
```
Output:
```
   Raghav Garg    16
Raghav Garg 11
```
➡️ `trim()` strips whitespace only from the **start and end** of the string, returning a new trimmed string; it leaves internal spaces untouched.

```js
let s = "   Raghav      Garg   ";
console.log(s, s.length);
let s2 = s.trim();
console.log(s2, s2.length);
```
Output:
```
   Raghav      Garg     20
Raghav      Garg 15
```
➡️ Confirms `trim()` only removes the outer whitespace; the extra spaces in the **middle** of the string ("Raghav      Garg") remain.

### `indexOf()`, `lastIndexOf()`, `charAt()`, and Bracket Indexing

```js
let s = "  Raghav Garg  ";
console.log(s, s.length);
let s2 = s.trim(); // s2 = "Raghav Garg"
console.log(s2, s2.length);
console.log(s2.indexOf('a'));
console.log(s2.lastIndexOf('a'));
console.log(s2.charAt(3));
console.log(s2[3]);
```
Output:
```
   Raghav Garg    16
Raghav Garg 11
1
8
h
h
```
➡️ `indexOf('a')` finds the **first** occurrence of `'a'` (index 1); `lastIndexOf('a')` finds the **last** occurrence (index 8). `charAt(3)` and `s2[3]` both return the same character at index 3 — two equivalent ways to access a character by position.

### `slice()` — Extracting Substrings

```js
let s = "raghavgarg";
console.log(s.slice(0));    // raghavgarg  -> from index 0 to end
console.log(s.slice(2));    // ghavgarg    -> from index 2 to end
console.log(s.slice(5));    // vgarg       -> from index i to end
console.log(s.slice(2,6));  // ghav        -> substring from index 2 to 5 (end index exclusive)
```

```js
let s = "raghavgarg";
console.log(s.slice(5));     // vgarg  -- substring from index i to end
console.log(s.slice(2,6));   // ghav   -- substring from index i to j-1
s2 = s.slice(2,5);
console.log(s, s2);
```
Output:
```
vgarg
ghav
raghavgarg ghav
```
➡️ `slice(i)` returns everything from index `i` to the end. `slice(i, j)` returns the substring from index `i` up to (but not including) index `j` — i.e., `j-1` is the last index included. The original string `s` is never modified.

### `split()` — Breaking a String into an Array

```js
let s = "raghav garg is a teacher at physics wallah";
console.log(s);
let arr = s.split();
console.log(arr);
```
Output:
```
raghav garg is a teacher at physics wallah
[ 'raghav garg is a teacher at physics wallah' ]
```
➡️ Calling `split()` with **no argument** returns the entire string as a single-element array — it isn't split at all.

```js
let s = "raghav garg is a teacher at physics wallah";
console.log(s);
let arr = s.split(' ');
console.log(arr);
```
Output:
```
raghav garg is a teacher at physics wallah
[
  'raghav', 'garg',
  'is',     'a',
  'teacher','at',
  'physics','wallah'
]
```
➡️ Passing `' '` (a space) as the **delimiter** splits the string into an array of words wherever a space occurs.

```js
let s = "raghav garg is a teacher at physics wallah";
console.log(s);
let arr = s.split(' ');
for (const ele of arr) {
    console.log(ele);
}
```
Output:
```
raghav garg is a teacher at physics wallah
raghav
garg
is
a
teacher
at
physics
```
➡️ A `for...of` loop **does** work on the resulting array (unlike directly on a string), printing each word on its own line.

```js
let s = "a,gh,b,rtf,w,v";
console.log(s);
let arr = s.split(',');
for (const ele of arr) {
    console.log(ele);
}
```
Output:
```
a,gh,b,rtf,w,v
a
gh
b
rtf
w
v
```
➡️ `split(',')` works with any delimiter character — here a comma — splitting the string into all the comma-separated values.

## 4. Template Literals (Backticks)

Template literals use backticks (`` ` ``) and allow embedding variables directly inside a string using `${}` — no manual `+` concatenation needed.

```js
let age = 30;
let exp = 10;
// console.log("My age is "+age+" and my experience is "+exp);
console.log(`My age is ${age} and my experience is ${exp}`);
```
Output:
```
My age is 30 and my experience is 10
```
➡️ Both approaches produce the same result, but template literals are cleaner and easier to read than manually concatenating with `+`.

### Quote Types & Escaping

```js
console.log("rag\"hav");     // rag"hav
console.log(`rag"hav`);      // rag"hav
console.log('rag"hav');      // rag"hav
console.log(`rag'hav`);      // rag'hav
```
Output:
```
rag"hav
rag"hav
rag"hav
rag'hav
```
➡️ A double quote (`"`) inside a double-quoted string must be escaped with `\"`. But using a different quote style (single quotes `'...'` or backticks `` `...` ``) to wrap the string lets you include the other quote character directly, with no escaping needed.

## 5. Arrays

### Basic Array Indexing
```js
arr = [1,6,8,3];
n = arr.length;
// for(let i=0;i<n;i++){
//     console.log(arr[i]);
// }
console.log(arr[2]);     // 8
```
➡️ Arrays in JS are conceptually similar to C++ `Vectors` or Java's `ArrayList` — dynamically resizable.

### Adding & Removing Elements
```js
arr = [1,6,8,3];
console.log(arr);             // [1, 6, 8, 3]
arr.push(9);                  // add at last
console.log(arr);             // [1, 6, 8, 3, 9]
arr.push(0);
console.log(arr);             // [1, 6, 8, 3, 9, 0]
arr.pop();                    // removes last element
console.log(arr);             // [1, 6, 8, 3, 9]
arr.unshift(2);                // add at first
console.log(arr);             // [2, 1, 6, 8, 3, 9]
arr.shift();                   // removes first element
console.log(arr);             // [1, 6, 8, 3, 9]
```

| Method | Action |
|---|---|
| `push(x)` | Adds `x` to the **end** of the array |
| `pop()` | Removes the **last** element |
| `unshift(x)` | Adds `x` to the **beginning** of the array |
| `shift()` | Removes the **first** element |

```js
const arr = [2,8,3,3];
arr.push(3);
console.log(arr);    // [2, 8, 3, 3, 3]
```
➡️ Even though `arr` is declared with `const`, `push()` still works — because `const` prevents **reassigning** the variable itself, not modifying the contents of the array it points to.

### Modifying Elements by Index
```js
let arr = [2,8,3,3];
arr[0] = 9;
console.log(arr);    // [9, 8, 3, 3]
```

```js
const arr = [2,8,3,3];
arr[0] = 9;
console.log(arr);    // [9, 8, 3, 3]
```
➡️ Modifying an element by index also works fine on a `const` array, for the same reason — the array reference itself isn't being reassigned.

```js
const arr = [2,8,3,3];
arr[0] = 9;
console.log(arr);    // [9, 8, 3, 3]
arr = 2.4;            // ❌ error
console.log(arr);
```
Output:
```
[ 9, 8, 3, 3 ]
TypeError: Assignment to constant variable.
```
➡️ Trying to **reassign** the entire `const arr` variable to a new value (`2.4`) throws an error, confirming that `const` locks the variable binding, not the array's internal contents.

```js
let arr = [2,8,3,3];
arr[0] = 9;
console.log(arr);    // [9, 8, 3, 3]
arr = 2.4;
console.log(arr);     // 2.4
```
➡️ With `let` instead of `const`, reassigning `arr` to a completely different value (and type) works without error — demonstrating JS variables can hold **any type at any time**, since JS doesn't require declaring data types.

### Mixed-Type Arrays
```js
arr = [4,"raghav",7.9,true];
console.log(arr);
```
Output:
```
[ 4, 'raghav', 7.9, true ]
```
➡️ Unlike strictly-typed languages, a single JS array can freely hold a mix of numbers, strings, and booleans together.

### Nested (2D) Arrays
```js
brr = [[1,2,2],[5,8,4]];
console.log(brr);
```
Output:
```
[ [ 1, 2, 2 ], [ 5, 8, 4 ] ]
```

```js
brr = [[1,2,2],[5,8,4,9,1]];
console.log(brr);
```
Output:
```
[ [ 1, 2, 2 ], [ 5, 8, 4, 9, 1 ] ]
```
➡️ Inner arrays don't need to be the same length — JS arrays are flexible and don't enforce a fixed shape like a true matrix would.

### Arrays Can Even Contain Arrays Mixed With Other Types
```js
arr = [4,"raghav",7.9,true,[4,7,4,8]];
console.log(arr);
```
Output:
```
[ 4, 'raghav', 7.9, true, [ 4, 7, 4, 8 ] ]
```

```js
console.log(typeof(arr));   // object
```
➡️ Even though `arr` is an array, `typeof` reports it as `"object"` — in JS, arrays are technically a specialized kind of object.

### `for...of` Loop on Arrays
```js
brr = [3,7,3,8,0,2];
console.log(brr);
for (let ele of brr) {
    ele *= 2;
}
console.log(brr);
```
Output:
```
[ 3, 7, 3, 8, 0, 2 ]
[ 3, 7, 3, 8, 0, 2 ]
```
➡️ Modifying the loop variable `ele` inside a `for...of` loop **does not** change the original array — `ele` is just a copy of each value, not a reference back into `brr`.

### `forEach()` Method
```js
brr = [3,7,6,8,0,2];
brr.forEach(ele => {
    console.log(ele);
});
```
Output:
```
3
7
6
8
0
2
```

### `forEach()` With Index
```js
brr = [3,7,6,8,0,2];
brr.forEach((ele, i) => {
    console.log(ele, i);
});
```
Output:
```
3 0
7 1
6 2
8 3
0 4
2 5
```
➡️ `forEach()` can take a **second parameter** (`i`) inside its callback, giving you the index of each element alongside its value — useful when you need to know an element's position during iteration.

## Quick Reference Summary

- Falsy values: `0`, `""`, `null`, `undefined`, `NaN`, `false` — everything else is truthy
- **Strings are immutable** — methods like `toUpperCase()`, `trim()`, `slice()` return a **new** string and never modify the original
- `slice(i)` → from index `i` to end; `slice(i, j)` → from `i` up to (not including) `j`
- `split(delimiter)` → turns a string into an array, split wherever the delimiter occurs; `split()` with no args returns a 1-element array (the whole string)
- `for...of` works on arrays returned by `split()`, but **not** directly on strings; `.forEach()` only works on arrays, not strings
- Template literals (`` `...` ``) embed variables via `${variable}` — cleaner than `+` concatenation
- Use a different quote style to avoid escaping a quote character inside a string
- `push`/`pop` (end), `unshift`/`shift` (start) — modify arrays in place
- `const` on an array locks the **variable binding**, not the array's contents — elements can still be changed/pushed, but the variable can't be reassigned to a new value
- JS arrays can mix types freely and hold nested arrays of differing lengths; `typeof` an array returns `"object"`
- Modifying the loop variable in `for...of` does **not** affect the original array (it's a copy); `forEach((ele, i) => ...)` also exposes the index
