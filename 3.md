# JavaScript Notes Part 3 — Objects, Functions, Callbacks, setTimeout & Math

## 1. Objects

An **object** is like a map/dictionary — it stores data as **key-value pairs** instead of indexed positions.

**Why objects over arrays?**
```js
// Array — you have to remember which index means what
var details = ["Raghav", 24, 92.5, false];

// Object — each piece of data has a meaningful name (key)
let x = {
    name: "Raghav",
    age: 24,
    percentage: 92.5,
    isMarried: false
};
```
Output of `console.log(x)`:
```
{ name: 'Raghav', age: 24, percentage: 92.5, isMarried: false }
```

### Keys with spaces — must use quotes
If a key contains a space, wrap it in quotes:
```js
let x = {
    name: "Raghav",
    "nick name": "Raghu",
    age: 24,
    percentage: 92.5,
    isMarried: false
};
```
Output:
```
{
  name: 'Raghav',
  'nick name': 'Raghu',
  age: 24,
  percentage: 92.5,
  isMarried: false
}
```

## 2. Accessing Object Properties

### Dot notation — works for simple (no-space) keys
```js
console.log(x.age);        // 24
```

### Bracket notation — required for keys with spaces; also works for simple keys
```js
console.log(x['is Married']);   // false
```

> Use **dot notation** by default. Use **bracket notation** when the key has spaces, special characters, or when the key is stored in a variable.

## 3. Looping Over an Object — `for...in`

`for...in` iterates over the **keys** of an object.

### Attempt 1 — `x.key` doesn't work (prints `undefined`)
```js
for (const key in x) {
    if (Object.hasOwnProperty.call(x, key)) {
        console.log(x.key);   // undefined for every iteration
    }
}
```
Output:
```
undefined
undefined
undefined
undefined
```
➡️ `x.key` literally looks for a property named `"key"` on the object — it does **not** use the variable `key`. That property doesn't exist, so it returns `undefined`.

### Attempt 2 — `console.log(key)` prints just the keys
```js
for (const key in x) {
    if (Object.hasOwnProperty.call(x, key)) {
        console.log(key);
    }
}
```
Output:
```
name
age
percentage
is Married
```

### Attempt 3 — `x[key]` correctly prints both key and value
```js
for (const key in x) {
    console.log(key, x[key]);
}
```
Output:
```
name Raghav
age 24
percentage 92.5
is Married false
```
➡️ `x[key]` uses the **value of the variable `key`** as the property name (bracket notation) — this is the correct way to dynamically access object properties inside a loop.

## 4. Functions

A **function** is a reusable block of code. You define it once and call it as many times as needed.

### Basic function — no return value
```js
function OnetoN(n) {
    for(let i = 1; i <= n; i++) {
        console.log(i);
    }
}

OnetoN(19);
```
Output: `1 2 3 4 5 6 7 8 ... 19`

### Function with return value
```js
function product(a, b, c) {
    return a * b * c;
}
```
Calling it:
```js
console.log(product(3, 8, 9));   // 216  (not 209 — slight typo in slides)
```

## 5. Callback Functions

> **Callback function ek esa function hota hai jo ek function ke andar pass hota hai.**
> (A callback function is a function that is passed inside another function as an argument.)

```js
function product(a, b, c) {
    return a * b * c;
}

function fun(x, y) {
    console.log(x - y);
}

fun(product(3, 8, 9), 7);
```
Output:
```
209
```
Here, `product(3,8,9)` is evaluated first (returns `216`), and its result is passed as the first argument `x` to `fun`. Then `fun` computes `216 - 7 = 209`.

➡️ The result of one function is **passed as an argument** into another function — this is the core idea of callbacks. The inner function (`product`) runs first and delivers its return value directly to the outer function (`fun`).

## 6. `setTimeout`

`setTimeout(callback, delayInMilliseconds)` — runs a function **once** after a specified delay.

### Basic example (inline anonymous function)
```js
setTimeout(function() {
    console.log("hello");
}, 2*1000);   // runs after 2 seconds

setTimeout(function() {
    console.log("mello");
}, 1*1000);   // runs after 1 second
```
Output (mello appears first because its delay is shorter):
```
mello
hello
```

### Passing a named function reference
```js
function hello() {
    console.log("hello");
}
function mello() {
    console.log("mello");
}

setTimeout(hello, 2*1000);   // runs hello() after 2 sec
setTimeout(mello, 1*1000);   // runs mello() after 1 sec
```
Output:
```
mello
hello
```
➡️ Notice `setTimeout(hello, ...)` — **no parentheses** on `hello`. Writing `setTimeout(hello(), ...)` would call `hello` immediately and pass its return value (`undefined`) to `setTimeout`, which is wrong. Passing `hello` (without `()`) passes the **function itself** as a callback to be called later.

### Using `setTimeout` inside a `for` loop — countdown with delay
```js
// print 1 to 10 but with delay of 1 sec after each number gets printed
for(let i = 30; i >= 1; i--) {
    setTimeout(function() {
        console.log(i);
    }, i * 500)
}
```
Output: numbers print from 1 up to 30 in order, each 500ms apart (because `i=1` has delay `500ms`, `i=2` has delay `1000ms`, etc., so they fire in ascending order of `i`).

## 7. Math Functions

The built-in `Math` object provides mathematical constants and functions.

```js
console.log(Math.abs(-7.6));          // 7.6    — absolute value
console.log(Math.max(5, 5.01));       // 5.01   — maximum of arguments
console.log(Math.min(-5, 1));         // -5     — minimum of arguments
console.log(Math.max(4, 8, 90, 399, 23));  // 399

console.log(Math.pow(3.14, 3.14));    // 36.33...  — 3.14 raised to 3.14
console.log(Math.log(2.81));          // 1.033...  — natural log (base e)

console.log(Math.sqrt(3.14));         // 1.772...  — square root
console.log(Math.cbrt(10));           // 2.154...  — cube root

console.log(Math.floor(-3.5));        // -4    — round DOWN to nearest integer
console.log(Math.floor(5.8));         // 5     — round DOWN
console.log(Math.ceil(5.8));          // 6     — round UP to nearest integer

console.log(Math.random());           // e.g. 0.732... — random float in [0, 1)
```

### `Math.random()` — generating random integers

`Math.random()` returns a float from `0` (inclusive) to `1` (exclusive).

**Random integer between 0 and 9 (inclusive):**
```js
let num = Math.floor(Math.random() * 10);
console.log(num);
```
- `Math.random() * 10` gives a float in `[0, 10)`
- `Math.floor(...)` converts it to an integer in `[0, 9]`

**Homework problems from the lecture:**
```js
// HOMEWORK — Write code to generate a random integer between 0 and 10 (included)
let num = Math.floor(Math.random() * 11);

// HOMEWORK — Write code to generate a random integer between -10 and 10 (included)

```

## Quick Reference Summary

- **Object** = key-value store (like a map/dictionary); keys are strings, values can be any type
- Keys with spaces must be in quotes: `"nick name": "Raghu"`
- **Dot notation** `x.age` — for simple keys; **Bracket notation** `x['is Married']` — required for keys with spaces
- **`for...in`** iterates over object keys; use `x[key]` (not `x.key`) inside the loop to get the value dynamically
- **Function** = reusable block of code; use `return` to send a value back
- **Callback** = a function passed as an argument to another function; the inner function runs and its return value is fed to the outer function
- **`setTimeout(fn, ms)`** — calls `fn` once after `ms` milliseconds; pass the function **reference** (`fn`), not a call (`fn()`)
- When `setTimeout` is used inside a loop, each iteration schedules a call at a different time — use `let` (not `var`) to capture the correct `i` per iteration
- **`Math.random()`** returns `[0,1)` — multiply by N and `Math.floor()` to get a random integer in `[0, N-1]`; multiply by `(N+1)` to include N
